\## Commands I practiced

\- git checkout -b: creates and switches to a new branch

\- git commit: saves changes to history

\- git revert: undoes a commit by adding a new one

\- git cherry-pick: copies one commit onto the current branch

\- git log --oneline --graph --all: shows the history



\## What I learned

Branches let me try things without breaking main, and my partner can work on her own branch at the same time. Revert was new to me, because it undoes a commit without deleting history. Cherry-pick is useful when I only want one commit from another branch.
